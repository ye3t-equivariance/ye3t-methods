# Fixed mlearn snapshot for the paper linear comparison

The six `.xyz` files and split records here are the fixed mlearn data snapshot
used by the Li, Mo, Cu, Ni, Si, and Ge comparison. `MANIFEST.json` records
the source data hashes and frame counts. The files match the data used in the
`ye3t-ace/examples/data/mlearn` study byte-for-byte.

Source: [materialyzeai/mlearn](https://github.com/materialyzeai/mlearn)
and the associated Zuo et al. MLIP benchmark. The upstream repository is
BSD-3-Clause licensed; its copyright notice and conditions are in
[LICENSE.mlearn](LICENSE.mlearn). The split JSON files record the selected
published train/test divisions.
